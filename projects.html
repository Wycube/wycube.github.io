Finite Automata Creator

http://github.com/Wycube/finite-automata

A library and web editor for creating DFA and NFA diagrams that can be simulated. Hosted at https://wycube.github.io/finite-automata.

NCSD/NCCH Dumper

http://github.com/Wycube/NCSD-tool

A tool for dumping files from NCSD and NCCH files (3DS archives) I made while messing around with some 3DS dumps. Also includes Python scripts for converting .bcwav and .bcstm to .wav files.

Game Boy Advance Emulator

http://github.com/Wycube/gambit

A Game Boy Advance Emulator written in C++. The emulator is cross-platform and uses GLFW for window creation, Dear ImGui for UI, and miniaudio for sound.

Cellular Automata Sandbox

http://github.com/Wycube/cell-base

A Cellular Automata sandbox where the rules are written in a Lua script and input to the program, which allows you to pan, zoom, and change cells.

Game Boy Emulator

http://github.com/Wycube/Smol-Boy

A Game Boy emulator written in C++, using SDL as a frontend for graphics, sound, and input.

Chip-8 Emulator

http://github.com/Wycube/fish-8

A Chip-8 Emulator written in C++.
